# AI Use Note

**Tool:** ChatGPT. **Purpose:** Help brainstorm and build a self-contained phishing-awareness teaching prototype.

**Representative requests:** “Make another, impressive project” and “Build a good one that actually works.”

**AI contributions:** HTML/CSS/JS prototype, six fictional examples, explanations, scanner rules, built-in checks, draft documentation.

**Student responsibility:** Open and test on a local browser, review accuracy, document any changed behavior, capture results, and explain why rules can be unreliable. Only claim tests and changes actually verified.

**Verification:** The app contains eight executable self-checks. Run them locally and record your actual results in `Test_Log.csv`; check UI controls manually.

**Limitations:** This is not a model-based detector. Rule matches do not prove phishing or safety. Examples and identities are fictional.

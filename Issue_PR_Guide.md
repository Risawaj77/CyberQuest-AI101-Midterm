# Required traceable issue and pull request

A real GitHub issue and pull request are **not yet created** by this ZIP. Do these steps to satisfy the rubric:

1. Create a repository and upload the project as an initial commit.
2. Open an Issue: `Improve scanner explanation for no matched clues`. Criteria: when no patterns match, the message must clearly say this does not prove safety.
3. Create a branch (e.g., `scanner-clarity`) and improve the scanner message wording or add another tested rule. Make a real code change.
4. Commit the change and open a Pull Request referencing the issue (`Closes #...`).
5. Review the diff and tests. Merge after review if permitted.
6. Save screenshots of Issue, PR, code diff, and test evidence with the submission.

Do not claim the issue/PR exists until those steps are actually done.
